# Progress

Use these pages for research updates and discussions with your supervisors.

- [Presentation template](template/presentation.md): a working example with
  formatting, code, figures, equations and tables.
- [Week 1](week-1/presentation.md): an empty page ready for your first update.

On desktop-width windows, select **Presentation mode** for a focused layout.
Use Left/Right or the arrow controls to move between sections, and **Esc** to exit.
The normal layout returns on narrow windows without forgetting your preference.

Add new weeks under `docs/progress/` and list them at the end of `nav` in
`mkdocs.yml`. The `.meta.yml` file enables the shared presentation template for
all pages in this directory. Separate sections with `---` followed by a heading.
