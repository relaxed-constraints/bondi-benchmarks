# API reference

This page reads the public functions and their docstrings from `src/`.
Update the module entries when you rename or extend the package.

The shared configuration parses Google-style docstrings. Use `Args:` for
parameter descriptions, `Returns:` for the return value and `Raises:` for
exceptions that callers should handle. These sections appear only when they are
documented; type annotations alone do not provide their descriptions. 

::: empty_project.hello

API rendering uses shared relcon-docs defaults with project-specific headings in
`mkdocs.yml`. See [Documentation](documentation.md) for configuration and upgrades.
