# BONDI Benchmarks

BONDI Benchmarks provides Python tools and [Yanex](https://relaxed-constraints.github.io/yanex/) experiments for database benchmarks.

## Available benchmarks

### YCSB

The [Yahoo! Cloud Serving Benchmark (YCSB)](https://github.com/brianfrankcooper/YCSB) measures throughput and latency for database operations.
The runner supports MongoDB and Couchbase.

1. [Install the project](installation.md).
2. [Run the first YCSB experiment](benchmarks/ycsb/experiments.md).
3. [Interpret the results](benchmarks/ycsb/results.md).

Use the [Python guide](benchmarks/ycsb/python.md) to run YCSB against an existing database.
